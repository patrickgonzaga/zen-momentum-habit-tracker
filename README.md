# Zen Momentum Habit Tracker

A minimalist, high-end habit tracker built with Next.js, Tailwind CSS, and Framer Motion. Features a deep charcoal aesthetic, glassmorphism UI, smooth animations, and local storage persistence. Track habits with a 7-day streak view and a real-time Momentum Score.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
